# Подключение почты через Brevo

Дата: 2026-10-18. Кому: владельцу. Что нужно: 5–10 минут твоего времени.

Почта — **основной** способ входа в кабинет: человек без Telegram должен
получать код письмом. Без почты кабинет работает только для тех, у кого есть
Telegram, то есть главный сценарий не закрыт.

Код уже готов и ждёт ключ — менять ничего не надо, только вписать значения.

---

## Почему аккаунт заводишь ты, а не я

Три причины, и все практические:

1. **Регистрация требует почтового ящика.** Письмо с подтверждением придёт
   **тебе**, не мне.
2. **Реквизиты принадлежат твоей компании** — домен, платёжные данные, владелец
   аккаунта. Вписывать их от твоего имени я не должен.
3. **Ключ API — секрет.** По правилам проекта он не проходит через вывод и не
   попадает в репозиторий.

Дальше по шагам то, что нужно сделать, и что после этого сделаю я.

---

## Шаг 1. Аккаунт Brevo

1. Зайди на `brevo.com` → **Sign up free**.
2. Зарегистрируйся на рабочий ящик (лучше на доменный, не на личный Gmail —
   меньше вопросов при верификации домена).
3. Подтверди регистрацию по письму.

**Тариф:** бесплатного достаточно — 300 писем в сутки. Для кодов входа это
с большим запасом: 300 входов в день при базе ~1300 пользователей.

## Шаг 2. Верификация домена — обязательна

Без неё Brevo либо не даст отправлять, либо письма уйдут в спам.

1. В Brevo: **Senders, Domains & Dedicated IPs** → **Domains** → **Add a domain**.
2. Введи домен-отправитель (у тебя рабочий `vpnbotfree.ru`).
3. Brevo покажет **записи DNS** — обычно это:
   - **DKIM** — TXT-запись вида `mail._domainkey...`;
   - **SPF** — TXT-запись вида `v=spf1 include:spf.brevo.com ~all`;
   - иногда **DMARC** — TXT на `_dmarc`.
4. Добавь эти записи **в DNS домена** — там, где управляется домен (панель
   регистратора или Fastpanel).
5. Вернись в Brevo и нажми **Verify**. Проверка занимает от минут до
   нескольких часов — DNS расходится не сразу.

**Важно:** SPF-запись может уже существовать. Вторая SPF-запись на одном домене
ломает проверку — тогда **дополни существующую**, а не создавай новую.

## Шаг 3. Адрес отправителя

1. **Senders** → **Add a sender**.
2. Имя: «VPN» или название сервиса; адрес — вида `no-reply@<домен>`
   (например `no-reply@vpnbotfree.ru`).
3. Подтверди адрес по письму.

**Почему `no-reply`, а не `support`:** на этот ящик люди будут отвечать, а
отвечать некому. Для кодов подходит адрес без ответа.

## Шаг 4. Ключ API

1. В Brevo: аватар справа сверху → **SMTP & API** → вкладка **API Keys**.
2. **Generate a new API key**. Имя — например `vpn-cabinet`.
3. **Скопируй ключ сразу** — второй раз он не показывается.
4. **Не отправляй ключ мне.** Впиши его сам (шаг 5).

**Важно:** нужен ключ со вкладки **API Keys**, а не SMTP-пароль. Они разные, и
для отправки через HTTP нужен именно первый.

## Шаг 5. Что вписать в конфиг

Файл `.env` на сервере кабинета (не в репозитории — он там не хранится).

```bash
MAIL_TRANSPORT=api
MAIL_FROM=no-reply@vpnbotfree.ru
MAIL_API_URL=https://api.brevo.com/v3/smtp/email
MAIL_API_KEY=<ключ из шага 4>
```

Значения `MAIL_TRANSPORT`, `MAIL_API_URL` и `MAIL_FROM` — фиксированные.
Секретное здесь только `MAIL_API_KEY`.

## Шаг 6. Проверка — обязательна, и её делаю я

Автотест этого **не проверяет**: доставляемость зависит от репутации домена и
фильтров почтовых сервисов, а не от кода.

Что проверяется:

1. Отправка на **mail.ru** — письмо доходит?
2. Отправка на **yandex.ru** — доходит?
3. Письмо **не в спаме** — папка «Спам» отдельно.
4. Заголовки: есть `DKIM-Signature` и `spf=pass` в письме?

**Если письмо в спаме — это не «мелочь».** Вход по почте будет «работать» в
тестах и не работать у человека. Причины обычно две: домен не верифицирован
(шаг 2) или новая репутация у Brevo — тогда помогает время и первые
«прогревающие» отправки.

**Что нужно от тебя для проверки:** скажи, когда ключ вписан, — и я прогоню
отправку и покажу результат по всем четырём пунктам.

---

## Что НЕ нужно

- **Не нужен свой SMTP-сервер.** Он уже реализован в коде, но для почты на том
  же хосте пришлось бы строить репутацию с нуля — и письма уходили бы в спам у
  mail.ru и yandex, пока она не наработана.
- **Не нужен платный тариф.** 300 писем в сутки покрывают вход с запасом.
- **Не нужно ничего менять в коде.** Транспорт под Brevo уже написан и покрыт
  тестом на формат запроса.
