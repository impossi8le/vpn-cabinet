## Как обращаться к докам

**1. Код — первоисточник истины.** Документ описывает замысел; что реально
работает — решает код и зелёный прогон. Где доки расходятся с кодом — прав код,
документ идёт на правку.

**2. Один факт — один дом.** У каждой сквозной темы есть документ-владелец.
Если факт нужен в другом документе, на него **ссылаются**, а не пересказывают.

**3. Три жанра — не путать.** Спека говорит, **что и почему**; план —
**какими заданиями**; прогон в CI и `pytest` — **чем доказано**. Не искать
«текущее состояние» в спеке: спека фиксирует замысел на дату.

**4. Документы не переписывают задним числом — дописывают поправку с датой.**
