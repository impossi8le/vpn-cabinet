волна начинается, когда закрыта предыдущая. Разработка — от тестов: у каждого
задания тест написан раньше кода.

## Порядок и зависимости

```
W0 ──► W1 ──► W2 ──► W3 ──► W4 ──► W5 ──► W6
                 └─────────────────────► (W4 и W5 можно параллельно)
```

- **W1 блокирует всё** — без модели аккаунта нечего связывать.
- **W2 и W3 идут по очереди**: связывать Telegram с почтой можно только когда
  почта работает.
- **W4 и W5 можно параллельно**, когда API подписок готов.
- **W6 — последняя**: живая база и почта подключаются, когда всё зелёное на моке.
