# План: боевые зависимости в точке входа кабинета (issue #45)

Дата: 2026-10-23. Задание — [#45](https://github.com/impossi8le/vpn-cabinet/issues/45).
Причина: выкладка на сервер. Юнит `cabinet-app.service` (в репозитории бота)
запускает кабинет командой `python -m cabinet`, а она сегодня собирает приложение
**на подставном боте**.

## Что чиним

`cabinet/__main__.py` вызывает `build_app()` без аргументов, и умолчания берут
подставные зависимости: `_default_store()` → `tests.fakes.FakeApi`,
`_default_mail_sender()` → отправитель с `FakeMailSender`. Выложенный так кабинет
войдёт любым адресом и покажет подписки из фикстур.

## Общие ограничения

- Кабинет **не ходит в базу** — только внутренний HTTP к боту на `127.0.0.1` с
  общим секретом (CLAUDE.md, «Границы сервиса»).
- **Секреты не печатать**: ни в код, ни в тесты, ни в коммиты, ни в вывод.
- Репозиторий публичный: ни IP, ни хостов, ни домены в код и тесты не попадают.
- Тесты — на подставных данных; живой бот подключается только в бою.
- Непустые тесты: снять защиту — тест обязан покраснеть.

### Task 1: точка входа собирает приложение боевыми зависимостями

**Файлы:** `cabinet/__main__.py`, `.env.example`, `tests/test_entrypoint.py` (новый).

**Требования:**

1. `python -m cabinet` собирает приложение боевыми зависимостями:
   - хранилище — `cabinet.bot_client.BotClient` по `BOT_BASE_URL` и общему секрету
     (адрес роутера бота, `http://127.0.0.1:8007` в бою);
   - отправитель писем — из окружения (`MailSender.from_env`, как уже умеет
     модуль).
2. **Без обязательных переменных окружения — не подниматься.** Отсутствие
   `BOT_BASE_URL` или секрета даёт понятный отказ и ненулевой код выхода.
   Молчаливый откат на подставного бота и есть дефект: неверная конфигурация не
   должна выглядеть рабочей.
3. **Имя переменной секрета — `CABINET_INTERNAL_SECRET`**: так его называет юнит
   выкладки в репозитории бота. В `.env.example` сегодня `BOT_INTERNAL_SECRET` —
   привести к одному имени, чтобы два имени не разошлись при развёртывании.
4. Порядок запуска не меняется: порт берётся из `CABINET_PORT`, слушаем
   `127.0.0.1`.

**Шаги:**

1. RED: тест «без переменных окружения запуск отвергается» и тест «с переменными
   собирается `BotClient` с теми же значениями».
2. Реализация: сборка зависимостей из окружения, отказ при отсутствии
   обязательных.
3. GREEN: `pytest tests/test_entrypoint.py` и весь набор; `ruff check .`,
   `ruff format --check .`.
4. Коммит: `Точка входа кабинета: боевые зависимости из окружения (#45)`.

**Готово, когда:** без окружения запуск отвергается внятным текстом; с окружением
собирается `BotClient`; весь набор зелёный; `tests/fakes.py` не тронут.

## Review Focus

- **Отказ вместо подстановки:** ни один путь не должен оставить подставной бот в
  боевом запуске.
- **Секрет не печатается** нигде, включая текст отказа.
- **Публичность:** в тестах и коде — только зарезервированные адреса
  (`example.com`, `127.0.0.1`).
- **Стенд не сломан:** `.claude/dev/cabinet_dev.py` собирает приложение сам и
  правки не замечает — проверить, что он по-прежнему поднимается.
